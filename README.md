# 🎓 Programacion II

Repositorio de la materia **Programación 2**: contiene la plantilla base del entorno de desarrollo, la guía de ejercicios y los ejemplos utilizados durante las clases.

Todos los proyectos son aplicaciones TypeScript + Node, con Jest para pruebas unitarias y una configuración de ESLint compartida (naming conventions, formato, reglas de POO) que estandariza el código en todo el repositorio.

## 📂 Contenido

### 🧰 `bootstrap/`

Plantilla base a partir de la cual se crea cada nuevo ejercicio o ejemplo. Incluye la configuración de TypeScript, Jest y ESLint ya resuelta, y un README con las instrucciones de instalación del entorno de desarrollo y una guía de cada regla de ESLint con ejemplos ❌ incorrecto / ✅ correcto.

### 📝 `guia-ejercicios/`

Ejercicios guiados de la cátedra, cada uno en su propia carpeta con su propio proyecto y README (enunciado + resumen de la implementación).

### 🧑‍🏫 `ejemplos-de-clase/`

Ejemplos usados en clase para introducir conceptos de forma interactiva, con su propio README explicando el objetivo y la implementación.
